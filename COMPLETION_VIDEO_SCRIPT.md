# Week 8 — Internship completion video script (2–3 minutes)

**Opening (0:00–0:15)**  
“Hello, this is my Flask blogging platform, Inkwell. It lets users publish posts, discuss them through comments, and find articles using search and sorting.”

**Project structure and setup (0:15–0:35)**  
Show the project folder and terminal. Briefly point out `app.py`, templates, static CSS, requirements and README. Show the app running locally.

**Authentication (0:35–0:55)**  
Register a demo account, sign out, and sign back in. Explain that passwords are stored as hashes.

**CRUD (0:55–1:25)**  
Create a post, open it, edit it, then show the delete control (you may keep the sample post instead of deleting it). Explain that only the author can edit or delete their own post.

**Comments (1:25–1:45)**  
Add a comment and show it under the post.

**Search, sorting and navigation (1:45–2:05)**  
Search for a keyword, switch newest/oldest, and navigate between home, sign in and write-post screens.

**Testing and deployment readiness (2:05–2:30)**  
Show the second-user permission test and README deployment instructions. Mention that production requires a strong secret, HTTPS, persistent database and CSRF protection.

**Closing (2:30–2:40)**  
“Those are the main features of Inkwell. Thank you.”

Record your actual screen and narration. Do not claim a deployment or test you have not completed.
