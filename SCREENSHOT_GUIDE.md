# Internship submission — screenshot evidence guide

Capture genuine screenshots from your own running app/browser. Do not fabricate evidence. Save images in `submission-screenshots/` and upload them with your project if the internship portal accepts attachments.

| Suggested filename | What to show | How to capture |
|---|---|---|
| `01-homepage.png` | Inkwell home page, post list, search and navigation | Open `http://127.0.0.1:5000` |
| `02-git-setup.png` | Git version and initialized repository | Terminal: `git --version`, `git status` |
| `03-flask-running.png` | Flask server running without errors | Terminal after `python app.py` |
| `04-register.png` | Registration form | Click Create account |
| `05-login.png` | Login form | Sign out, then open Sign in |
| `06-create-post.png` | New post editor filled with sample content | Sign in and click Write a post |
| `07-post-detail.png` | Published post detail | Submit the post |
| `08-edit-post.png` | Edit form with existing post data | Click Edit on your own post |
| `09-comment.png` | Comment section showing a submitted comment | Submit a comment |
| `10-search-filter.png` | Search results and sort dropdown | Search for a known title term |
| `11-permission.png` | 403 page when a second user tries to edit first user's post | Sign in as account B and manually open account A's edit URL |
| `12-github.png` | GitHub repository file list and latest commit | Push code, then open repository page |

## Capture on Windows
- Press `Win + Shift + S`, select the relevant app/browser region.
- Save as PNG with the filenames above.
- Keep terminal screenshots readable and avoid showing passwords, secret keys or personal information.
